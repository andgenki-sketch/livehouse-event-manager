## 最終版1回更新後の限定動作確認
1. WordPressバックアップ。必ずプラグインが「接続テストのみ」になっていることを確認。
2. 未使用の日付・新規テストイベント1件を作成。WordPressとVercel Previewの両方を同じIDのみに限定して初回公開。投稿ID、TECローカル/UTC日時、OPEN/START、料金、画像を確認。
3. 同じテストイベントをアプリで変更。投稿IDが**変わらない**こと、変更項目のみ反映されること、重複がないこと、TEC日時が正しいことを確認。
4. 同イベントでHP公開OFF。WordPressが下書きになったことを確認。
5. WordPressで「接続テストのみ」に戻し、Vercel Preview書込をOFF。テストイベントは非公開のまま。
6. 完全なログ・GitHubコード整合・運営上の管理者承認を経て、**別操作**でWordPress全許可とVercel本番許可をONにする。
